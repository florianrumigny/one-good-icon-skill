# Explore

Use this phase until the user selects one or two candidates.

## Build the evidence brief

Inspect what exists before asking for more. Accept any combination of:

- idea or written product brief;
- product UI, brand system, repository assets, or screenshots;
- multiple visual references;
- photo, sketch, print, texture, or footprint;
- existing icon;
- previously generated and selected concept.

For each reference, record the transferable principle and its role. Examples: centered monolith composition; broad negative-space cut; enamel-like depth; warm two-color contrast; friendly asymmetry. Mark logos, characters, signature shapes, or trade dress that must not be copied.

If essential material is missing, ask only for what changes the directions. Otherwise state the assumptions and continue.

## Diverge

Create about 4–6 directions. Name each direction by its visual thesis, not by letter. Give each a distinct axis position across symbol strategy, geometry, depth/material, composition, or emotional tone. Color swaps and detail changes are variations, not directions.

For each direction provide:

- a one-sentence concept and why it fits the product;
- the visual construction and focal idea;
- the preserved reference principles;
- the main risk or cost;
- an ImageGen prompt that is complete enough to rerun.

Keep prompts icon-specific: one dominant symbol, centered readable composition, controlled edge density, deliberate background, no device mockup, no text unless the concept truly requires a letterform, and no baked-in OS mask. Use negative constraints to prevent UI screenshots, multiple tiles, generic sparkle/rocket/shield clichés, and copied reference marks.

Use native ImageGen to materialize the set when available. Keep generation metadata or prompts with each output. Preserve the untouched source files.

## Present and stop

Show candidates at equal visual weight in one board, with names and short tradeoffs outside the art. When ImageGen is unavailable, use a compact comparison table as the board and keep one complete generator-ready prompt under each direction. The board is for comparison; keep individual full-resolution origins separately when images exist.

Do only a quick sanity check for obvious illegibility or accidental similarity. Do not reconstruct vectors, build Icon Composer layers, package platforms, or run the full test matrix.

Complete Explore when the user selects one or two candidates or asks for a new divergent round.
