# Ship

Ship only an explicitly approved icon. Start from the untouched selected origin, retain it as an identifiable `.origin.*` source where practical, and record the approved candidate, source path, generation prompt/metadata when available, requested platforms, and target stack/version.

## Choose the master

- Reconstruct simple geometry as vector when it produces faithful curves, repeatable alignment, and editable color.
- Keep complex texture, illustration, lighting, or painterly detail as a high-resolution raster master.
- Split layers only when depth, material, animation, appearance, or platform tooling uses them.

Compare any reconstruction against the selected origin side by side for overall mass, with an overlay for geometry, and with isolated layer inspection for alpha or matte contamination when useful. Repair the authoring source, then regenerate derivatives. Fidelity outranks cleanliness. Keep the origin even when a reconstruction wins.

## Build requested adapters

Load the relevant platform reference. Detect installed tools and project versions before choosing commands or config fields. Keep adapter outputs in clear platform folders and avoid overwriting user assets without confirmation.

For unsupported or unavailable tools, produce prepared sources plus exact remaining manual steps. Never describe an unrun validator as passed.

## Verify

Check, as applicable:

- required files exist and dimensions/formats match the detected platform rules;
- transparency and edge padding are intentional;
- configuration resolves to the delivered files;
- platform build or validation tools accept the output;
- rendered previews match the approved icon under relevant appearances, masks, sizes, and context;
- the source origin, editable master, and derived assets are all retained.

Finish with a delivery manifest: source of truth, derived files, configuration changes, commands/validators actually run, visual checks performed, fallbacks, and deferred work.
